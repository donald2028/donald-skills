# Donald Agent Infrastructure

Give a project one operating contract and one hand-maintained Skill source. Keep authoring, runtime
installation, and cross-runtime distribution separate.

## Workflow

1. Read the target repo's contracts, Skill directories, runtime discovery paths, Git status, and
   optional subagent registry.
2. Default to root `skills/` as an unregistered authoring source. If the user explicitly chooses a
   runtime-native repo directory, use that directory as the sole source instead of mirroring it.
3. Choose one layout: flat `<source>/<skill>/SKILL.md`, or categorized
   `<source>/<category>/<skill>/SKILL.md` only for genuine Skill families.
4. Decide independently whether entry routing, governance, or recurring subagents are needed.
5. Preserve existing runtime content unless legacy ownership and unchanged-content evidence prove
   it was generated by this Skill.

Read `references/architecture.md` when designing a structure, `references/migration.md` before
changing an existing repository, and `references/workbuddy.md` when WorkBuddy or CodeBuddy is in
scope.

## Initialize

Use the initializer for new scaffolds. It writes only missing files unless `--force` is passed.

```bash
python scripts/init_project_agent_infra.py <repo> \
  --layout flat \
  --with-entry \
  --with-governance \
  --with-subagents
```

The three `--with-*` switches are independent and optional. By default, the initializer uses root
`skills/` and creates no runtime Skill directories, sync script, compatibility links, or related
ignore rules. When the user explicitly wants a runtime-native source, pass its repository-relative
path with `--skills-root`, for example `--skills-root .agents/skills`; do not create another source.

Subagent generation is separate. `--with-subagents` creates `agents/registry.yaml` and
`agents/sync_agents.py`; define only real recurring roles, then run the generator and `--check`.

## Migrate Legacy Mirrors

Preview before applying:

```bash
python scripts/migrate_legacy_runtime_skills.py <repo>
python scripts/migrate_legacy_runtime_skills.py <repo> --apply
```

The migration removes the recognized sync script, legacy contract and ignore rules, and only
manifest-owned links or unchanged copies. It preserves canonical root `skills/` and stops without
deleting anything when ownership is invalid or runtime content has changed.

## Verify

Run the structural audit against the selected source and the project's normal tests:

```bash
python scripts/audit_project_skills.py --skills-root <skills-root> --strict
```

For the default source, confirm `.agents/skills/`, `.claude/skills/`, `.codebuddy/skills/`, and
`.workbuddy/skills/` do not exist. Editing a Skill must not recreate them. Runtime installation or
distribution is a separate, explicit operation for a named consumer.

## Invariants

- `AGENTS.md` is canonical; runtime adapters contain only runtime-specific additions.
- A project has exactly one hand-maintained Skill source and one layout.
- Skills are self-contained and globally unique.
- Required workflow dependencies use `**REQUIRED SUB-SKILL:** Invoke <skill-name>` without missing
  targets, self-reference, or cycles.
- Audit output is evidence; the main agent owns semantic decisions.
